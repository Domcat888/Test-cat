屏幕像素尺

Test cat · UI Inspection

● 准备就绪
全屏 UI 检测

只要显示在电脑屏幕上，就可以测量

适用于 Android / iOS 模拟器、浏览器、设计稿和任何桌面软件。开始后会冻结当前屏幕，方便进行像素级检查。

开始前设置

快捷键可选，不设置也可以直接点击开始。

＋
透明叠加参考图

可选设计稿或历史截图；进入测量后可调整透明度、位置和大小。

启动后：拖拽框选元素，连续框选两个区域即可测量间距。

本次可用功能

  • 坐标与尺寸X / Y / W / H 原始屏幕像素
  • 屏幕标尺横纵刻度与十字准星
  • 间距测量两个区域的水平、垂直距离
  • 对齐检测边缘、中心线与偏移量
  • 色值吸取HEX、RGB 与像素放大镜
  • 透明叠加参考图透明度、缩放和拖动
  • 结果导出复制检测文案或保存标注截图
