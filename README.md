# Test cat

Test cat 是一个面向测试工程师的跨平台桌面工具箱，目标是把日常测试里高频、零散、容易烦人的事情集中到一个软件里：投屏、性能监控、弱网、日志、安装包管理、测试数据、截图录屏、公式计算，以及 AI 辅助测试。

当前版本：`v0.9.1`  
支持平台：macOS / Windows

## 功能总览

| 模块 | 能力 |
| --- | --- |

| iOS 投屏 | iPhone USB 只读投屏，适合查看和录制测试现场 |
| 安卓性能监控 | CPU、内存、GPU、网络、磁盘、App、设备指标采集，报告保存、对比和导出 |
| iOS 性能监控 | iPhone 设备级 / App 进程级性能采集，Crash / Jetsam / Performance 日志导入 |
| 弱网测试 | Android 场景化弱网模拟，支持地铁、电梯、隧道、2G / 3G、自定义参数 |
| 日志分析 | Android logcat 实时读取、筛选、高亮 Crash / ANR / Exception，并导出日志报告 |
| 文件对比 | 文本、代码、JSON、XML、CSV、XLSX、图片、二进制、文件夹差异对比 |

## 本地预览

无需打包即可本地打开：

- macOS：双击 `本地预览.command`
- Windows：双击 `本地预览.bat`

也可以在终端运行：

```bash
npm install
npm run preview
```

开发环境需要 Node.js `22.12.0` 或更高版本。软件打开后按 `F12` 可以打开或关闭开发者工具。

## AI 模型怎么接入

Test cat 第一版不把大模型直接塞进软件里，而是调用外部模型服务。这样软件体积更小，macOS / Windows 都更好兼容，后续更换模型也不用重新打包。

进入 `设置 → AI 设置`，填写下面几项：

| 配置 | 小白解释 | 示例 |
| --- | --- | --- |
| API Key | 模型服务的钥匙，没有它就不能调用 AI | `sk-...` |
| Base URL | 模型服务的大门地址 | `https://api.openai.com/v1` |
| Model | 你要调用哪个模型 | `gpt-4.1-mini`、`deepseek-chat` 等 |
| Temperature | AI 发散程度，越低越稳定 | 测试用例建议 `0.2` - `0.4` |

AI 设置里可以开启 / 关闭 AI 功能，也可以锁定配置。锁定后配置项不可编辑，避免误改 Key、Base URL 或模型名。

### AI 测试助手

AI 测试助手目前包含 4 个场景：

- 测试用例生成：粘贴需求或拖入文件，结合附加条件生成测试用例，支持 Excel / XMind 导出。
- 报错解释：粘贴报错信息，生成原因、影响范围和下一步处理建议。
- Bug 单生成：把现象、截图、日志整理成可直接提单的文案。
- 日志总结：把长日志提炼成异常点、关键链路和排查方向。

需求文件支持 `txt`、`md`、`json`、`xml`、`csv`、`html`、`yaml`、`log`、`docx`、`xlsx`、`png`、`jpg`、`jpeg`、`webp`、`gif`。Word / Excel 内嵌图片会作为图片附件发送给支持视觉的模型；如果当前模型不支持视觉，图片内容可能无法被模型理解。

测试用例生成提示词完全走设置里的配置。设置页点击“编辑提示词”会打开大编辑器，关闭后自动保存。

## 截图与录屏

截图与录屏在 `设置 → 截图与录屏` 中配置：

- 可开启 / 关闭整个功能。关闭后快捷键不会响应，设置页也不能启动截图或录屏。
- 截图快捷键、录屏快捷键支持点击输入框后直接按组合键记录。
- 截图默认动作支持小预览、打开编辑器、复制到剪贴板、贴到屏幕、保存 PNG。
- 截图编辑器支持矩形、箭头、文字、马赛克等常用标注。
- 录屏采用框选区域录制，录制中会保留红色区域边框，控制条会避开录制区域。
- 录屏保存优先使用 MP4；如果当前系统环境不支持 MP4 编码，会自动回退 WebM。

## 安卓相关能力

### 安卓投屏

安卓投屏支持 Android USB 设备检测、一键部署 scrcpy 服务、独立投屏窗口、鼠标触控、键盘输入、返回 / 主页 / 最近任务、旋转、截图、全屏与关闭手机屏幕。

竖屏画面会完整等比显示，进入横屏游戏时自动跟随画面方向并重新适配。投屏运行时可以继续使用 Test cat 主窗口里的其他工具，也可以开启“窗口置顶”让手机画面保持在其他软件上方。

设备连接后可以读取手机型号、Android 版本、系统构建、分辨率、CPU、物理内存、电量、温度、网络、ADB 连接方式，以及当前前台 App 的包名、版本号和 versionCode。读取结果会整理成缺陷环境文案，可一键复制到缺陷单。

### 安卓性能监控

安卓性能监控以独立窗口运行，可多选 CPU、内存、GPU、网络、磁盘、应用和设备指标，并以实时曲线展示 Android 设备数据。

支持一键读取当前前台 App；开始测试时可自动识别，并可在测试中跟随切换后的游戏或被测 App。填写包名后可测量冷启动耗时，并补充应用内存、FPS、卡顿和崩溃指标。

结束测试时会弹出报告命名窗口。报告保存在 Test cat 本机数据目录，支持 JSON、离线 HTML 和真实 `.xlsx` 工作簿导出，两份历史报告可以比较平均值与变化比例。

部分 GPU、显存、功耗指标依赖手机厂商是否开放对应系统节点。不支持时界面会明确显示“设备不支持”，不会生成模拟数据。

### 弱网测试

弱网测试面向 Android 设备，支持一键部署手机端弱网组件，并通过 USB 建立弱网通道。

内置场景包括深山老林、电梯、地铁、隧道穿行、2G 网络、3G 网络，也可以手动调整：

- 下行带宽
- 上行带宽
- 基础延迟
- 延迟抖动
- 断流强度

停止测试后会自动恢复正常网络。若手机系统禁止自动确认 VPN，需要按界面提示在手机上手动允许。

### 日志分析

日志分析通过真实 ADB logcat 实时读取 Android 日志。支持整机日志和指定 App 日志两种范围，可按日志级别、普通关键字、接口名、玩家 ID 等条件过滤，也可以一键识别当前前台 App。

Crash、ANR、Exception、Error 和错误堆栈会自动高亮，并汇总到异常事件列表。日志可复制，也可导出为原始 `.log` 或带异常颜色标记的 HTML 报告。

### 安装包管理

安装包管理支持 APK / IPA 文件管理和 APK 基础信息解析，包括：

- 包名、应用名称、版本号、versionCode
- Min SDK / Target SDK
- 权限列表
- 文件大小
- MD5 / SHA1 / SHA256
- APK 证书 MD5

Android 支持一键安装、卸载、清除数据、多设备批量安装和历史版本对比。安装失败时会尽量解释原因，例如签名不一致、版本回退、存储不足、CPU 架构不兼容等。

## iOS 相关能力

### iOS 投屏

iOS 投屏以独立窗口运行，只读取已信任 iPhone 的屏幕画面，不发送点击、滑动、按键或文字输入。

模块优先使用免费的 `libimobiledevice` 工具链，也支持安装 Python `tidevice` 后自动回退到 `tidevice screenshot`。当前实现采用 USB PNG 截图轮询，适合查看与录制测试现场，不等同于高帧率 H.264 视频流。

### iOS 性能监控

iOS 性能监控通过内置 Python 运行环境与 `pymobiledevice3` 调用 Apple DVT，采集真实的 CPU、内存、设备 FPS、GPU 利用率、电池温度、电量和充电状态；选择用户 App 后，还可以采集 App 进程 CPU 与 `physFootprint` 内存。

设备未公开的指标会显示为不可用，不生成模拟数据。

正式安装包会携带与系统架构匹配的采集引擎，用户不需要安装 Python、`pymobiledevice3` 或配置环境变量。Windows 仍需要系统存在 Apple Mobile Device 驱动，可通过安装 Apple Devices 或 iTunes 获得。

停止测试后报告会自动保存在 Test cat 本机数据目录，支持 JSON 导入、JSON / 离线 HTML 导出，以及两份报告的平均值、峰值、变化比例对比。

## 效率工具

### 文件对比

文件对比支持文本、代码、JSON、XML、CSV、XLSX、图片、二进制和整个文件夹。

CSV / XLSX 会以左右双栏的真实工作表网格展示，能够识别公式变化并还原百分比、日期等常见显示格式。文本差异支持逐处双向合并、缩略导航和大文件插入 / 删除对齐。文件夹对比支持扩展名过滤、排除目录、内容哈希判断和带二次确认的单项同步。

全部差异均可导出为 HTML 或 Excel 可见报告，最近记录只保存在本机。

### Mock 数据生成器

Mock 数据生成器支持常用测试数据批量生成：

- 手机号
- 身份证号
- 邮箱
- 用户名
- 地址
- 时间戳
- UUID
- JSON 模板数据
- 边界值数据

生成结果支持批量复制和导出 CSV。

### 公式运算

公式运算适合测试数值规则、奖励规则、金币计算、倍率计算等场景。

可以先创建变量词，例如“鱼”“炮倍”“加成”“金币数”，再编写公式：

```text
（炮倍 * 加成） + 鱼 = 最终金币数
```

之后只需要输入变量值，工具会自动代入计算。支持公式模板、历史记录，以及公式 / 变量词导入导出。

### 时间戳转换和计算器

时间戳转换支持秒、毫秒、微秒、纳秒和日期时间互转。计算器支持鼠标、键盘、四则运算、括号和取余。

## 首页、主题和提醒

首页全部工具卡片都可以拖拽调整顺序，排序结果会保存在本机。

侧边栏“测试待办”支持高、普通、低优先级，并按全部、待完成、已完成筛选。默认高优先级权重最高。任务支持设置闹钟时间，Test cat 会在还差 30 分钟、10 分钟、5 分钟时通过桌面宠物提醒。

外观支持浅色、深色、紫色护眼三种主题。

桌面宠物支持月薪喵和 Doro，可随机移动、跳舞，并提醒喝水、站立和待办事项。如果宠物处于关闭状态，待办提醒会临时出现，提醒结束后自动回窝。

## 本地更新

关于页支持从 GitHub Releases 检查更新，更新源为 `Domcat888/Test-cat`。

软件会根据当前系统自动选择 mac universal、Windows x64 或 macOS Catalina Intel 兼容包。发现新版本后，可一键下载到系统下载目录并打开安装包。下载地址限制为 GitHub 官方 Release 域名，降低误下载风险。

## 打包

```bash
# macOS，生成 DMG 与 ZIP
npm run build:mac

# macOS Catalina Intel 兼容包
npm run build:mac:catalina

# Windows，建议在 Windows 机器上执行，生成安装版与便携版
npm run build:win
```

输出文件位于 `release/`。未签名安装包首次打开时可能触发系统安全提示；正式分发时建议配置 Apple Developer ID 与 Windows 代码签名证书。

## 开发说明

正式安装包会携带 Android Platform Tools 和 iOS 性能采集运行时。源码开发、预览和打包会先准备运行环境：

```bash
npm run prepare:runtimes
```

生成的运行时资源不提交到 Git。

后续接入新模块时，建议在 `src/main.js` 增加受控的主进程能力，再通过 `src/preload.js` 向渲染层暴露最小化接口。保持 `contextIsolation` 与 `sandbox` 开启，不要直接在页面中启用 Node.js。
