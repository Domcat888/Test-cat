# iOS Valeria runtime component

This directory contains an isolated screen-capture backend derived from the
`feature/valeria` work in `doronz88/pymobiledevice3`. It is launched as a
separate Python process and passes the iPhone's H.264 stream to Test cat.

Source: https://github.com/doronz88/pymobiledevice3/tree/feature/valeria
